# Carbon Control AJ199 — Tech Dashboard v1.9

## Что подключено
- Добавлены ресурсы из пакета Tech Dashboard: `icons/ico`, `icons/png`, `icons/svg` и `themes`.
- Навигационные иконки теперь выбираются из `icons/png/light` или `icons/png/dark` в зависимости от темы Windows/настройки приложения. Размер иконок навигации уменьшен до 16 px.
- Общие иконки действий используют тот же тематический набор, где для кнопки назначена иконка через `set_button_icon`.
- Подключаются файлы `themes/tech_dashboard_light.qss` и `themes/tech_dashboard_dark.qss` поверх базовых стилей приложения; пользовательский цвет акцента переносится в основные акцентные цвета QSS.
- Автоматический режим темы продолжает проверять настройку Windows раз в 3 секунды.
- Существующие страницы, локальные профили и диагностика мыши сохранены. Диагностика фиксирует реальные события Windows, которые получает тестовая область; она не измеряет электрическое состояние переключателей и не подтверждает работу сенсора вне приложения.
- DPI и другие параметры устройства остаются локальными значениями интерфейса: подтверждённый протокол отправки команд AJAZZ AJ199 Carbon не добавлен.

## Установка и запуск
1. Распакуйте архив в новую папку, например `G:\sowt maus\Protatip\1\ВЕР18`.
2. Убедитесь, что Python установлен по пути `G:\PY\python.exe`. Если путь отличается, поправьте `PYTHON_EXE` в `setup.bat`.
3. Один раз запустите `setup.bat`.
4. Для последующих запусков используйте `run.bat`.

Не переносите только `main.py`: папки `icons` и `themes` необходимы для отображения новых ресурсов.

## Проверка
- `main.py` прошёл проверку синтаксиса Python.
- Архив проверен на целостность.
- Полный запуск GUI на Windows в текущей среде не выполнялся; после первого запуска проверьте обе темы, иконки и страницу диагностики.
